## How to use?
- [Download](https://github.com/BADtochka/BLoadscreen/releases/latest/download/BLoadscreen.zip) latest build from releases
- Extract somewhere
- Edit config in `/assets/config.js`
- Copy loadscreen to resources folder
- Start resource (or add to autostart)
